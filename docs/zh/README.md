# 中文交接资料索引

这套资料面向接手维护和执行压测的同事。当前目标是在手头可用板卡上运行 CPU/GPU/NPU 用例，记录稳定性、显式错误、超时和性能变化。没有外部调压接口，因此不输出低电压 Vmin 或功耗收益结论。已有外部锁频时，只记录其设置与实际读数，本工具不修改频率。

建议阅读顺序：

1. [交接报告](交接报告.md)：代码位置、版本、已完成内容和限制。
2. [用例总表](用例总表.md)：所有 Monitor 配置、各类负载原理、参数和判定含义。
3. [编译指南](编译指南.md)：Windows/Linux 集中构建及 NDK 条件。
4. [使用指南](使用指南.md)：接板、部署、运行、收集、重放、报告。
5. [设计指南](设计指南.md)：模块边界、数据流、校验协议和扩展方式。
6. [七天压测与日志交接](七天压测与日志交接.md)：每日计划、异常处理、日志字段和主管周报口径。

可编辑表格位于 `outputs/01a17824-deaf-7751-918c-2543b1250eaf/压测交接表.xlsx`，可打印报告位于 `docs/zh/交接附件/中文交接报告.html`。工作表中的每日记录初始为空，不能作为已执行的压测数据。原始日志中的 JSON 字段名、错误码、命令和路径保持原文，解释采用中文。
